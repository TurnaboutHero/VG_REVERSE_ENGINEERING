# Death action and structure classification evidence

This is a selected, sanitized evidence package. Corpus IDs match the ordering in the 2026-09-08 endgame package. Full executable/resources, raw player recordings and broad memory dumps are excluded.

- `direct-death.json`: observed direct-practice record/screen relationship; precise transition capture is unavailable.
- `corpus.json`: strict-framed layer-0 ADD-1/candidate action comparison over 56 recordings, retaining clock statuses.
- `correlation-summary.json`: exact matches plus an explicitly analytical 100ms window; remaining end-tail actions.
- `source-type-proof.json`: recorded actor to definition index to named installed-resource entry, with SHA256 values.
- Native source excerpts are decompiler output for the exact executable identified by `manifest.json`; generated variable names and apparent prototypes may be incomplete. Claims are restricted to the traced data flow and inspected consumers.

These findings do not prove final-match counter acceptance, exact screen latency, universal actor IDs, or normalized kill credit.
