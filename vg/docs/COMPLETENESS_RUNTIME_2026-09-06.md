## 바뀐 행동

M6처럼 녹화된 마지막 시점까지 이벤트가 이어져도 경기 종료 근거가 없으면 전체 경기 통계를 확정하지 않는다. Core는 `data_complete=None`과 `completeness_reason`을 출력한다. V2는 `completeness_unknown`으로 분류하여 KDA·승패·골드의 index 승인을 보류한다. 분석용 부분 골드는 기존대로 값과 `gold_status`를 함께 제공하므로, 사용자는 index-ready 출력을 쓰거나 상태를 확인해야 한다.

M6 결과 이미지의 시간은 직접 육안으로25:51임을 확인했다. 파일은149개(0..148)로 중간 누락이 없고, 마지막 플레이어/일반 사망은1486.23초다. 유일한 크리스탈 대역 후보는1221.31초로 너무 이르다. 기존 비율1486/1490=.997은 녹화 범위 안의 활동을 설명할 뿐, 실제 경기1551초까지 기록했다는 증거가 아니다. 숫자를 임의로 보충하지 않고1486초 추정값을 유지했다.

## 재검증

- 새 M6형 회귀 테스트: 수정 전15개 중1개가 예상대로 실패했다.
- 수정 후 대상 테스트28개, 전체 unittest221개 모두 통과했다.
- 작업 명세·코드 품질 독립 검토: 승인, 지적 사항 없음.
- 원격 실제 시작 파일60개를 다시 디코딩했다. 완전성 판정과 새 사유 필드만 제외한 전체 JSON의 SHA256이60/60개 모두 기준과 동일했다. 이 비교에는 duration, KDA, 미니언, 아이템, 골드, 오브젝트, 좌표와 모든 기존 보조 필드가 포함된다.
- 플레이어514행, 좌표100672개, map_side500행, 신화 오브젝트151건, 터렛412건으로 동일했다. 출력 건수는 사건별 정확도 검증이 아니다.
- 기존 아이템 칸 수 픽스처:60명 중49명 일치,11명 과잉, 부족0명으로 동일했다. 종류 정확도를 새로 측정한 것은 아니다.
- `python -m vg.analysis.truth_comparison`의 전체 출력은 이전 기준과 동일했다(줄바꿈 정규화 후 비교). 이 도구는 여전히 경로의Incomplete 문자열로 분모를 나누므로 자동 완전성 검증기로 해석하지 않는다.
- 실제 M6 디렉터리를 `build_index_ready_export`에 입력했다.1경기/10명 기본 정보가 유지되고, winner 및 플레이어 kills/deaths/assists/gold/minion_kills 필드는 index 출력에서 제외됐다.

## 판정 범위의 변화

| 경로 | 이전 | 이후 |
|---|---|---|
| Core True |52|26|
| Core False |3|3|
| Core None |5|31|
| V2 complete_confirmed |53|33|
| V2 incomplete_confirmed |7|7|
| V2 completeness_unknown |0|20|

V2의 이전 수치는 기준 커밋의 판정 함수를 현재와 같은60개 신호에 적용해 비교했다. Core는 기존 전체 출력 스냅샷과 비교했다. 경로 기준 시작 파일 수이며 고유 경기 중복 제거 수가 아니다.

정답11경기 중 M4·M6·M7이 두 경로 모두 판단 불가가 됐다. M9는 불완전 판정을 유지했고, 나머지7경기는 완전 판정을 유지했다. M4/M7의 보류는 알려진 정확도 악화가 아니라 종료 증거 부족으로 발생하는 수용 범위 감소다.

Core와 v2는 여전히 같은 완전 판정 개수를 내지 않는다. V2는 플레이어 사망이 오래됐더라도 늦은 크리스탈·일반 사망·아이템 신호가 일치하는 기존 경로를 유지한다. Core에는 그 추가 대조 신호가 없으므로 더 좁은 긍정 기준을 쓴다.

## 남은 문제

이 변경은 KDA나CS 수치를 복원한 것이 아니다. M5/M6의+1 KDA, M6의 미니언 오차, 판매/소모품으로 인한 최종 아이템 과잉은 남는다. 완전성 판정도 현재 알려진 신호에 근거한 휴리스틱이므로 절대적 보증은 아니다. 불완전·판단 불가 결과의 숫자는 과잉과 누락이 모두 가능해 무조건 하한값으로 취급하지 않는다.

다음 연구는 종료 증거가 없는 파일의 원본/재생 종료를 독립적으로 대조하고, 종료 시점 전후 이벤트가 실제 결과화면 집계에 반영되는 조건을 찾는 것이다. 원자료 없이M6의 누락된 통계를 정답 숫자로 채우거나 시간 임계값을 튜닝하지 않는다.
